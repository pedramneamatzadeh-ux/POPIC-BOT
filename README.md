# POPIC-BOT

ربات عمومی چندکاربرهٔ تلگرام برای ساخت و انتشار پست‌های متنی طولانی (تا ۴۰۹۶ کاراکتر) همراه با **پیش‌نمایش عکس داخل خود پیام** (از طریق `LinkPreviewOptions` و لینک پستِ عکس در کانال عمومی جداگانه).

## قابلیت‌ها
- **عمومی و چندکاربره با دیتابیس اختصاصی:** هر کاربر پس از `/start` صاحب یک دیتابیس ایزوله‌شده (`data/workspaces/user_<id>.db`) می‌شود و می‌تواند کانال‌ها، پست‌ها و ادمین‌های خودش را داشته باشد.
- **سیستم نقش مالک / ادمین:** هر مالک می‌تواند کاربرانی را به عنوان ادمین فضای کاری خود اضافه کند؛ هنگام `/start` یا از دکمهٔ `🔄 تغییر فضا / نقش` می‌توان بین فضای شخصی (مالک) و فضای ادمینی جابه‌جا شد (ادمین‌ها به تنظیمات و بک‌آپ دسترسی ندارند).
- **حفظ کامل فرمت‌بندی متن تلگرام (`entities`):** Bold، Italic، Spoiler، لینک‌های متنی، Custom Emoji و … تا سقف ۴۰۹۶ کاراکتر.
- **اتصال لینک پستِ عکس:** با چسباندن لینک یا فوروارد مستقیم از کانال عمومی عکس‌ها، با تنظیم محل پیش‌نمایش (بالا یا پایین متن) و اندازه (بزرگ یا کوچک).
- **پیش‌نمایش زنده و تحویل دوگانه:** ارسال مستقیم به کانال هدف یا تحویل پیام آماده در پی‌وی؛ لغو ساخت پست هیچ رکوردی در دیتابیس ذخیره نمی‌کند.
- **دکمه‌های شیشه‌ای اختیاری:** افزودن و حذف دکمه‌های URL هم هنگام ساخت پست و هم در آرشیو `📂 پست‌های ذخیره‌شده`.
- **بک‌آپ امن:** دریافت فایل `.db` فضای کاری شخصی (بدون ارسال `.env`).

## راه‌اندازی
1. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
2. کپی `.env.example` به `.env` و مقداردهی `BOT_TOKEN` (مقدار `OWNER_ID` اختیاری است و فقط برای دریافت گزارش خطاها و مشاهدهٔ آمار کل ربات استفاده می‌شود).
3. اجرای ربات:
   ```bash
   python3 main.py
   ```
4. اجرای تست‌ها:
   ```bash
   python3 tests/run_all.py
   ```
