# POPIC-BOT

ربات تلگرام برای ساخت و انتشار پست‌های متنی طولانی (تا ۴۰۹۶ کاراکتر) همراه با **پیش‌نمایش عکس داخل خود پیام** (از طریق `LinkPreviewOptions` و لینک پستِ عکس در کانال عمومی جداگانه).

## قابلیت‌ها
- حفظ کامل فرمت‌بندی متن تلگرام (`entities`: Bold، Italic، Spoiler، لینک‌های متنی، Custom Emoji و …) تا سقف ۴۰۹۶ کاراکتر
- اتصال لینک پستِ عکس (با چسباندن لینک یا فوروارد مستقیم از کانال عمومی عکس‌ها) با تنظیم محل پیش‌نمایش (بالا یا پایین متن) و اندازه (بزرگ یا کوچک)
- پیش‌نمایش زنده در پی‌وی + انتخاب **ارسال مستقیم به کانال هدف** یا **تحویل پیام آماده در پی‌وی**
- پشتیبانی اختیاری از افزودن دکمهٔ شیشه‌ای (URL Button) زیر پست
- آرشیو و مدیریت پست‌های ذخیره‌شده (پیش‌نمایش مجدد، ارسال مجدد، ویرایش پست منتشرشده در کانال، حذف)
- پنل تنظیمات مالک (مدیریت ادمین‌ها، کانال‌های مقصد، پیش‌فرض‌های پیش‌نمایش و نسخهٔ ربات) + بک‌آپ دیتابیس و `.env`

## راه‌اندازی
1. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
2. کپی `.env.example` به `.env` و مقداردهی `BOT_TOKEN` و `OWNER_ID`.
3. اجرای ربات:
   ```bash
   python3 main.py
   ```
4. اجرای تست‌ها:
   ```bash
   python3 tests/run_all.py
   ```
