# POPIC-BOT

ربات عمومی چندکاربرهٔ تلگرام برای ساخت، زمان‌بندی و انتشار پست‌های متنی (تا ۴۰۹۶ کاراکتر) با پشتیبانی از سه حالت نمایش تصویر (**بدون عکس**، **عکس عادی** یا **پیش‌نمایش عکس از طریق لینک**)، کانال‌ها و گروه‌ها، ویرایش پست‌های قدیمی و مدیریت ابرمالک.

## قابلیت‌ها
- **عمومی و چندکاربره با دیتابیس اختصاصی:** هر کاربر پس از `/start` صاحب یک دیتابیس ایزوله‌شده (`data/workspaces/user_<id>.db`) می‌شود و می‌تواند کانال‌ها/گروه‌ها، پست‌ها و ادمین‌های خودش را داشته باشد.
- **سیستم نقش مالک / ادمین:** هر مالک می‌تواند کاربرانی را به عنوان ادمین فضای کاری خود اضافه کند؛ هنگام `/start` یا از دکمهٔ `🔄 تغییر فضا / نقش` می‌توان بین فضای شخصی (مالک) و فضای ادمینی جابه‌جا شد (ادمین‌ها به تنظیمات دسترسی ندارند).
- **حفظ کامل فرمت‌بندی متن تلگرام (`entities`):** Bold، Italic، Spoiler، لینک‌های متنی، Custom Emoji و … تا سقف ۴۰۹۶ کاراکتر همراه با **نام اختیاری پست** برای جست‌وجوی سریع در آرشیو.
- **سه حالت انعطاف‌پذیر برای تصویر پست:**
  1. `🚫 بدون عکس`: پست کاملاً متنی بدون پیش‌نمایش لینک (`LinkPreviewOptions(is_disabled=True)`).
  2. `📷 عکس عادی`: ارسال عکس مستقیم روی پیام (`send_photo`) با بررسی خودکار سقف ۱۰۲۴ کاراکتری کپشن تلگرام و پیشنهاد تبدیل به لینک یا ویرایش متن در صورت بیشتر بودن.
  3. `🔗 عکس به صورت لینک`: اتصال لینک یا فوروارد پست از کانال عمومی عکس‌ها (`LinkPreviewOptions`) تا سقف ۴۰۹۶ کاراکتر متن همراه با تنظیم محل پیش‌نمایش (بالا/پایین) و اندازه (بزرگ/کوچک).
- **دکمه‌های شیشه‌ای پیشرفته:** افزودن و تنظیم کامل دکمه‌ها (تا ۱۲ دکمه و حداکثر ۴ دکمه در هر ردیف) هم هنگام ساخت پست، هم در آرشیو `📂 پست‌های ذخیره‌شده` و هم در `🛠 ویرایش پست قدیمی` — شامل ۳ نوع (**لینکدار**، **نمایشی پاپ‌آپ بدون لینک** و **کپی متن**)، **۴ رنگ** (معمولی/شفاف، آبی، سبز، قرمز) و تغییر چیدمان ردیف‌ها و ترتیب دکمه‌ها.
- **پیش‌نمایش زنده و آپدیت چندکاناله:** در `📂 پست‌های ذخیره‌شده` نیز پیش‌نمایش واقعی پست بالای سر پنل کنترل نمایش داده می‌شود؛ در صورت انتشار در چند کانال/گروه، هنگام آپدیت می‌توانید مقصد موردنظر (یا همه) را انتخاب کنید و در صورت تغییر بین «عکس عادی» و «بدون عکس/لینک»، با تأیید شما پیام قبلی حذف و نسخهٔ جدید ارسال می‌شود.
- **پشتیبانی از کانال‌ها، گروه‌ها و سوپرگروه‌ها:** امکان افزودن کانال، گروه و سوپرگروه با فوروارد، `@username`، لینک عمومی یا آیدی عددی در `⚙️ تنظیمات`.
- **زمان‌بندی دقیق (تاریخ میلادی + ساعت تهران):** انتخاب روز، ماه، سال میلادی و ساعت `HH:MM` به وقت `Asia/Tehran` با جلوگیری از انتخاب زمان گذشته، انتخاب یک یا چند مقصد، اجراگر پس‌زمینهٔ مقاوم در برابر ری‌استارت (بدون ارسال تکراری) و تب اختصاصی `⏰ زمان‌بندی‌شده‌ها` با صفحه‌بندی روزانه + `🔍 جست‌وجو`.
- **ویرایش پست‌های قدیمی کانال/گروه (`🛠 ویرایش پست قدیمی`):** فوروارد یا ارسال لینک پیام‌های ارسالی همین ربات برای ویرایش متن، حذف/تغییر عکس و ویرایش دکمه‌ها.
- **بک‌آپ کامل و مدیریت کاربران ویژهٔ مالک `.env`:** دکمهٔ `💾 بک‌آپ` (خروجی `.zip` شامل `registry.db` و دیتابیس‌های کاربران، بدون `.env`) و دکمهٔ `👥 مدیریت کاربران ربات` در `📊 آمار` (بن/رفع بن با تأیید و ارسال پیام مستقیم با تأیید) فقط برای `OWNER_ID` تنظیم‌شده در `.env` در دسترس هستند.

## راه‌اندازی
1. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
2. کپی `.env.example` به `.env` و مقداردهی `BOT_TOKEN` (مقدار `OWNER_ID` اختیاری است و برای دریافت بک‌آپ `.zip`، گزارش خطاها، مشاهدهٔ آمار کل و مدیریت کاربران استفاده می‌شود).
3. اجرای ربات:
   ```bash
   python3 main.py
   ```
4. اجرای تست‌ها:
   ```bash
   python3 tests/run_all.py
   ```
