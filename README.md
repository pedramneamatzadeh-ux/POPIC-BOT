# POPIC-BOT

ربات عمومی چندکاربرهٔ تلگرام برای ساخت و انتشار پست‌های متنی (تا ۴۰۹۶ کاراکتر) با پشتیبانی از سه حالت نمایش تصویر (**بدون عکس**، **عکس عادی** یا **پیش‌نمایش عکس از طریق لینک**).

## قابلیت‌ها
- **عمومی و چندکاربره با دیتابیس اختصاصی:** هر کاربر پس از `/start` صاحب یک دیتابیس ایزوله‌شده (`data/workspaces/user_<id>.db`) می‌شود و می‌تواند کانال‌ها، پست‌ها و ادمین‌های خودش را داشته باشد.
- **سیستم نقش مالک / ادمین:** هر مالک می‌تواند کاربرانی را به عنوان ادمین فضای کاری خود اضافه کند؛ هنگام `/start` یا از دکمهٔ `🔄 تغییر فضا / نقش` می‌توان بین فضای شخصی (مالک) و فضای ادمینی جابه‌جا شد (ادمین‌ها به تنظیمات دسترسی ندارند).
- **حفظ کامل فرمت‌بندی متن تلگرام (`entities`):** Bold، Italic، Spoiler، لینک‌های متنی، Custom Emoji و … تا سقف ۴۰۹۶ کاراکتر.
- **سه حالت انعطاف‌پذیر برای تصویر پست:**
  1. `🚫 بدون عکس`: پست کاملاً متنی بدون پیش‌نمایش لینک (`LinkPreviewOptions(is_disabled=True)`).
  2. `📷 عکس عادی`: ارسال عکس مستقیم روی پیام (`send_photo`) با بررسی خودکار سقف ۱۰۲۴ کاراکتری کپشن تلگرام و پیشنهاد تبدیل به لینک یا ویرایش متن در صورت بیشتر بودن.
  3. `🔗 عکس به صورت لینک`: اتصال لینک یا فوروارد پست از کانال عمومی عکس‌ها (`LinkPreviewOptions`) تا سقف ۴۰۹۶ کاراکتر متن همراه با تنظیم محل پیش‌نمایش (بالا/پایین) و اندازه (بزرگ/کوچک).
- **دکمه‌های شیشه‌ای پیشرفته:** افزودن و تنظیم کامل دکمه‌ها (تا ۱۲ دکمه و حداکثر ۴ دکمه در هر ردیف) هم هنگام ساخت پست و هم در آرشیو `📂 پست‌های ذخیره‌شده` — شامل ۳ نوع (**لینکدار**، **نمایشی پاپ‌آپ بدون لینک** و **کپی متن**)، **۴ رنگ** (معمولی/شفاف، آبی، سبز، قرمز) و تغییر چیدمان ردیف‌ها و ترتیب دکمه‌ها.
- **پیش‌نمایش زنده و تحویل تمیز:** ارسال مستقیم به کانال هدف یا «تحویل در پی‌وی» (با حذف خودکار پیام کنترل پیش‌نمایش تا فقط پست آماده در پی‌وی باقی بماند)؛ لغو ساخت پست هیچ رکوردی در دیتابیس ذخیره نمی‌کند.
- **بک‌آپ کامل ویژهٔ مالک `.env`:** دکمهٔ `💾 بک‌آپ` فقط برای `OWNER_ID` تنظیم‌شده در `.env` نمایش داده می‌شود و پس از `wal_checkpoint` یک فایل `.zip` شامل `registry.db` و تمامی فایل‌های `data/workspaces/*.db` ارسال می‌کند (بدون فایل `.env`).

## راه‌اندازی
1. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
2. کپی `.env.example` به `.env` و مقداردهی `BOT_TOKEN` (مقدار `OWNER_ID` اختیاری است و برای دریافت بک‌آپ `.zip`، گزارش خطاها و مشاهدهٔ آمار کل ربات استفاده می‌شود).
3. اجرای ربات:
   ```bash
   python3 main.py
   ```
4. اجرای تست‌ها:
   ```bash
   python3 tests/run_all.py
   ```
